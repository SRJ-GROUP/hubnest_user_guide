# HubNest OS Workspace Overview

The HubNest OS desktop application organizes your daily business tasks into a unified, responsive interface.

## Key Areas
- **Sidebar Navigation**: Instant access to HubMeet, HubCRM, HubHRMS, Calling Hub, and Notifications.
- **Multi-Hub Tabs**: Run CRM and HRMS side-by-side without opening multiple browser windows.
- **System Tray**: Keeps HubNest running silently in the background for incoming calls and notifications.
