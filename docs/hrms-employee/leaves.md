# 04. Apply Leaves & Balance (`/employee/leaves`)

The **Leaves** module allows employees to check real-time leave balances, plan vacations, submit time-off applications with handover notes, and monitor manager approval workflows.

## 🧭 Key Sections & Workspaces

### 1. Real-Time Balance Cards
* View exact remaining quotas for **Casual Leave (CL)**, **Sick Leave (SL)**, and **Paid Leave (PL)**.

### 2. Submitting a Leave Application
* Select leave type, specify start and end dates (with half-day options), provide a reason, and nominate a colleague for task handover.
* Track the multi-tier approval progress: Direct Manager $\rightarrow$ HR Operations.
