# 03. My Tasks & Deadlines (`/employee/tasks`)

The **Tasks** module provides employees with a dedicated personal task manager—organizing daily deliverables, project milestones, and due dates across intuitive status lanes.

## 🧭 Key Sections & Workspaces

### 1. Personal Task Board
* View tasks assigned to you across **To Do**, **In Progress**, **In Review**, and **Completed** lanes.
* Drag and drop cards to reflect live progress and notify project leads.

### 2. Task Details & Subtasks
* Check off completed subtask items, log productive hours, and post updates in comment threads.
