# 13. Profile (`/hr/profile`)

The **Profile** module allows HR Specialists to manage their personal account settings, verify administrative security permissions, configure two-factor authentication (2FA), and delegate approval authorities during out-of-office periods.

## 🧭 Key Sections & Workspaces

### 1. Identity & Credentials
* Manage personal contact details, mobile numbers, and administrative notification preferences.
* Update account passwords with real-time complexity validation.

### 2. Security & Out-of-Office Delegation
* Configure Two-Factor Authentication (2FA) via mobile authenticator apps.
* Nominate a temporary **Delegate Approver** to handle recruitment and leave sign-offs during personal vacations.
