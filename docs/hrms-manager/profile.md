# 09. Profile (`/manager/profile`)

The **Profile** module allows Department Managers to maintain personal contact details, configure security settings, and set up temporary out-of-office approval delegation.

## 🧭 Key Sections & Workspaces

### 1. Personal Info & Security
* Manage contact phone numbers, profile avatars, and notification preferences.
* Enable Two-Factor Authentication (2FA) for secure supervisory access.

### 2. Supervisory Approval Delegation
* Nominate a peer manager or senior team lead to handle leave and attendance approvals while you are on scheduled vacation.
