# 03. Tasks & Delegation (`/manager/tasks`)

The **Tasks** module enables Department Managers to create assignments, delegate work to team members, set due dates, and monitor project delivery across agile Kanban lanes.

## 🧭 Key Sections & Workspaces

### 1. Departmental Kanban Board
* Move task cards across **To Do**, **In Progress**, **In Review**, and **Completed** lanes.
* Drag and drop cards, set priority flags (`Low`, `Medium`, `High`, `Urgent`), and assign subtasks.

### 2. Workload Balancing
* Evaluate team capacity to ensure balanced task distribution and prevent burnout.
