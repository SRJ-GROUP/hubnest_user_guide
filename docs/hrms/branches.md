# Manage Branches & Multi-Location Setup

The **Manage Branches** module (`/admin/branches`) allows enterprise organizations to operate across multiple geographic locations while maintaining unified centralized administration.

![Manage Branches](../assets/images/HRMS/branches.png){ width="100%" }

---

## 🏢 Multi-Branch Features
* **Geographic Entity Setup**: Create and manage physical offices (e.g. Mumbai HQ, Delhi Branch, Bengaluru Tech Hub).
* **Location-Specific Settings**: Configure branch timezones, contact details, and branch heads.
* **Regional Holiday Calendars**: Assign state-specific public holidays tailored to each regional branch.
