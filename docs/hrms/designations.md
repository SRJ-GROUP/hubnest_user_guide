# Designations & Hierarchy Levels

The **Designations** module (`/admin/designations`) establishes clear job titles, seniority levels, and compensation bands across the entire organization.

![Designations Management](../assets/images/HRMS/Designations.png){ width="100%" }

---

## 💼 Key Features
* **Standardized Job Titles**: Create consistent role names (e.g. Software Engineer, Senior Consultant, VP of Sales, HR Director).
* **Hierarchy Mapping**: Map designations to organizational levels to automate reporting lines.
* **Role Permissions Alignment**: Connect designations to baseline RBAC permissions.
