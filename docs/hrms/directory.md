# Employee Directory

The **Employee Directory** module (`/admin/employees-list`) provides a comprehensive, visual directory of all team members with instant search and contact shortcuts.

![Employee Directory](../assets/images/HRMS/Employee%20Directory.png){ width="100%" }

---

## 🪪 Key Features
* **Visual Profile Cards**: Browse employee cards displaying profile avatars, full names, job designations, and department tags.
* **Instant Filtering**: Search dynamically by name, email, department, or office branch.
* **Collaboration Shortcuts**: Quick action icons to launch a direct team chat message or send an email.
