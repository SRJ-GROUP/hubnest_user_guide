# Team Messages & Real-Time Chat

The **Messages** module (`/admin/messages`) provides an integrated corporate chat platform powered by WebSocket technology (STOMP/SockJS), facilitating instant communication without third-party messaging tools.

![Team Messages](../assets/images/HRMS/Messages.png){ width="100%" }

---

## 💬 Key Features
* **Direct Messaging (1-on-1)**: Instant messaging between employees, managers, and HR specialists.
* **Departmental Channels**: Collaborate within dedicated team groups.
* **File Attachments**: Securely share documents, screenshots, and spreadsheets directly in chat threads.
