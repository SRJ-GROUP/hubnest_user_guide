# Notifications & Broadcast Announcements

The **Notifications** module (`/admin/notifications`) enables leadership to publish organization-wide announcements, emergency broadcasts, and track event alert histories.

![Notifications Management](../assets/images/HRMS/Notification.png){ width="100%" }

---

## 🔔 Key Features
* **Company-Wide Broadcasts**: Post announcements (e.g. holiday notices, policy updates, town hall invites) to all active staff.
* **Targeted Delivery**: Scope notices to specific branches or departments.
* **3-Channel Unified Dispatch**: Dispatches alerts simultaneously to In-App bells, connected Slack channels, and SMTP emails.
