# Administrator Profile & Account Security

The **Profile** module (`/admin/profile`) manages the authenticated administrator's personal credentials, emergency contacts, and account security.

![Administrator Profile](../assets/images/HRMS/profile.png){ width="100%" }

---

## 👤 Key Features
* **Personal Profile Management**: Update full name, phone number, and avatar photo.
* **Security & Passwords**: Update administrative passwords with BCrypt hashing and review active login sessions.
* **Two-Factor Authentication (2FA)**: Strengthen account security with Keycloak-integrated multi-factor authentication.
