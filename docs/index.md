# Welcome to HubNest User Guide

Welcome to the official documentation and user guide for **SRJ HubNest**, the unified enterprise operating workspace for modern businesses.

HubNest brings your entire organization under one roof—connecting video meetings, customer relationship management, human resource workflows, VoIP calling, multi-channel notifications, and centralized billing into a single desktop and cloud ecosystem.

## 💡 How to Get Started

1. **[Download HubNest OS](getting-started/installing-desktop-app.md)**: Install the native Windows 64-bit app (`.msi`).
2. **[First-Time Login](getting-started/login-and-setup.md)**: Authenticate with your enterprise SSO credentials.
3. **[Workspace Setup](desktop/workspace.md)**: Customize your active hubs and notifications.
